Start here

Enter help to see the commands.

cat hello.c
clang hello.c -o hello.wasm
./hello.wasm

Connect commands

echo "Hello browser" > message.txt
cat message.txt | cat
./hello.wasm &
wait

Use ↑ and ↓ for command history. Use Ctrl+C to stop a program.

Your files

Upload source files or WASI Preview 1 programs. Run a program with ./program.wasm.

Files in /home/user are saved in IndexedDB, the browser file database. Files in /tmp are temporary.

AIHC and WASI components are not installed. The C toolchain loads when you first use it.
